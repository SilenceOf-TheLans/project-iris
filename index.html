Project IRIS — EKF Simulator

Extended Kalman Filter simulator for aerospace exam prep.

Load a CSV file or use the synthetic LEO pass. Press Run EKF.

LEO: 6-state orbit, range + range-rate updates. Attitude: 4-state 2D orbit, direct position updates.

CSV rows are sparse measurements and are used directly; the R slider adds runtime sensor noise and sets the assumed measurement noise. The clean truth curve is regenerated from the two-body orbit equation seeded by the first row, so it stays smooth even with only 5 points.

Mode 1 (11 columns) selects LEO; Mode 2 (5 columns) selects the planar 2D filter automatically. Headers and strictly increasing times are validated on load.

The lower chart plots position error versus time; the dashed horizontal line is the running mean. Scroll to zoom it, drag to pan, double-click or press 0 to reset the view. Simulation Speed changes playback pacing only (0.1×–10×), not the filter math.
